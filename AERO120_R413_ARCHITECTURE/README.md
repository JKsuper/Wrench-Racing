# AERO120 R4.13-LC8｜工程验证打样候选

**结论：文件可交打印店做首轮工程验证样；先确认切片和支撑，再打印完整A件。尚不能作为已验证的长期使用成品或量产文件。**

## 本次检查与修正

1. LC7最终装配不碰撞，但百叶沿正面装入在2–16mm段会撞固定中脊。LC8把中脊移到可拆前盖D，A仍为一体密封风道；先装百叶，再装前盖，15个装入位置回归通过。LC7旧文件不再交店。
2. C型材孔改为Ø7通孔，M4/M5/M6螺栓任选一种，配相应槽型T螺母及大平垫。安装壁6mm、面板68mm宽44mm高，三孔每次选两孔；20mm孔距、大垫座和筋避让已检查。不能把通孔兼容当作承载通用。
3. 四份实际STL独立读入，网格闭合且各为一个连通件；与对应STEP体积和尺寸一致。源文件/模型报告有哈希校验，30项几何测试通过。见12_Prototype_Review。

## 发给打印店什么

直接发送 `12_Prototype_Review/PRINT_SHOP_RIGHT_LC8`，里面只有当前右侧4件产品STL、清单和交店说明。它是06_STL文件的核验副本，不是新增构件。A/B/C/D各1件，单位mm，必须作为独立对象导入、自动落平台/摆盘，不能按装配坐标合并成一件打印。左侧需重新导出并复核，不能把默认右侧当成左右一对。

另有 `OPTIONAL_FIT_COUPONS_NOT_PRODUCT` 三个可选接口试片，总理论净重约6.5g，用于轴孔/夹持及风扇角部试配，不能当作产品件或强度试样。可先报价试片或小件B/D，确认工艺和配合，再打印大件A/C。

## 四件产品

- A：一体风道/风扇壳及加强四角，没有主风道分件接缝。
- B：活动双百叶，正面装入，M4×16＋薄平垫＋摩擦片夹持。
- C：底盖与四向安装支架，M4固定底盖，型材接口可选M4/M5/M6。
- D：带Wrench Racing浮雕及固定中脊的可拆前脸，左右通用、品牌不反写。前盖可单独换色；未装D可做功能试装但外观不同。

## 打样前仍需确认

A在当前Z朝上姿态存在约110.4×64mm内顶面，必须由店铺确认方向、支撑以及能从Ø110入口/前出口完整清理。B叶厚1.4mm、D中脊2mm、A壁厚1.8mm，请店铺确认不会删薄壁或粘连。此处未运行切片，不提供未经验证的G-code。

用户已确认螺钉为非沉头；百叶/底盖/前盖按头下16mm和每片0.5mm薄平垫核对。0.8/1mm普通平垫不能未经计算直接替换。型材螺栓长度需按6mm壁厚、选定大垫及实际T槽/T螺母另定。

先将C装到型材再装A，以便操作螺钉头。四向为几何换位；前侧贯穿风口的高立柱、后向出线口附近的螺钉与线束，需要实物确认，不能默认全座舱适配。

普通PETG（FDM）首样需记录牌号、层向、层高、壳线、局部实心与支撑方案。支架、耳根、垫圈承压区的强度和蠕变没有实测；M6不可按金属连接扭矩直接拧塑料。装配后还要做防松、漏风、风量/噪声与温升测试。

## 材料和成本

当前四件CAD实体约234.66cm³，按PETG密度1.27净重约298g；不含支撑、裙边、损耗和填充差异。单侧100元仍未取得完整报价。白字图片为涂字/多色示例，报价先按单件单色；暂停换丝可能同时改变前伸中脊的颜色，不保证只改变文字。

源码沿用03_Codex/simple_lc2。当前30项测试及4文件独立核验只说明对应检查范围，不能代替实际工艺和性能放行。当前A/C/D接口及中脊归属已变，请成套使用LC8，不混用旧版。
