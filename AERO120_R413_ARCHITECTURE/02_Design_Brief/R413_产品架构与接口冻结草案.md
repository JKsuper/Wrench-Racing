# AERO120 R4.13｜模块化短风道架构（设计冻结草案）

> 2026-10-29。此文档是基于现有 R4.12 CadQuery 实体和代码核对的结构方案，不是已经完成的 R4.13 STEP/STL、强度或流量认证；新接口的孔距需建模后通过实物样件验证。

## 一、总体产品架构（单侧）

**A 主体风道：** 一件固定不动的 90° 短弯道，保留 120mm 底部风扇法兰及 105×105mm 四孔，内部保持连续密封，不再集成高复杂度 STRIKE 前脸。主体外壁设置局部加强座作为受力接口，不把金属支架放进风扇密封层。

**B 可替换造型前罩：** 单独小件打印，外观采用斜切中凸、上下内凹双槽的 STRIKE 语言。与 A 通过短搭接止口（建议搭接深 5–7mm，具体以 CAD 测试确定）、细窄闭孔泡棉和隐藏的底部 M3 紧固件连接；由定位键承受扭转，螺钉仅负责夹紧。外侧不露饰板螺丝。视觉分型线沿底部阴影线布置。

**C 可调导风芯：** 前罩内部一件联动双叶片内芯，左右两侧小转轴/螺丝形成共同俯仰轴，靠弹性垫圈摩擦定位，预设±12°为设计目标。中间外观凸脊固定在 B 上，活动叶片藏在深凹风槽内，避免重启“外挂饰板”。不让整个风道承担活动关节载荷。建议后续按使用需求开发偏转 ±10° 的水平调节支架或小型转向内芯，不在第一版同时堆两轴万向球节。

**D 独立金属连接件：** A 外壁共用同一套承力固定座；配置 D1 立柱内侧安装和 D2 横梁安装两种金属适配件。利用 4040 T 槽 M5 螺栓，用户松开固定件后可以自行更换安装高度，**没有滑轨**。连接件不得阻挡 120mm 风扇进气。左右使用相同固定座，可镜像支架。

**E 用户自备风扇及防护网：** 外置 120×120mm，厚度按 25/38/50/55mm 做几何验收；风扇方框直接贴合 A 法兰，仅需要风扇—法兰一片封闭泡棉垫。确认实际型号出线口、安装孔形状与紧固方式。

## 二、从 R4.12 修复的具体结构问题

| 旧结构 | R4.13 解决思路 | 为什么 |
|---|---|---|
| STRIKE 前脸与弯道一体 | 单独更换 B | 风口造型迭代无需重印全部主体；分色更容易 |
| 风口无活动机构 | 小型 C 内芯俯仰 | 不必转动风道/重风扇，活动件尺寸小 |
| 金属环架夹在风扇和法兰之间 | D 只连接 A 外壁加强座 | 受力与密封分离，少一道接合面和一片垫 |
| 原支架难适应不同型材 | D1/D2 共用 A 接口 | 一种风道适配前立柱或横梁，不增加滑轨 |
| 横梁可能挡住底置风扇吸气 | 横梁支架抬升/错位布局 | 必须验证风扇进气面下方净空，建议初始设计目标≥30mm，非已验证最低值 |

## 三、现有 CAD 的已知参数（已核对 R4.12 源码）

- R4.12 单侧风道有效实体：约 **296.50cm³**；原安装支架与风道密封界面采用两片 1.5mm 名义 EPDM 垫片。
- 风扇法兰外框 **124×124mm**、厚 **5mm**；标准风扇四孔距 **105×105mm**；风扇 120×120mm 外框，25/38/50/55mm 深度均以外置方式处理。
- R4.12 风扇孔 Ø4.6mm，名义中心通孔 Ø110mm。
- 当前风道轴向为向上进风、向左水平出风，约 90° 转向。
- R4.13 **尚未建模**，不应引用 296.5cm³ 作为新版本体积或新报价。

## 四、拟冻结接口（待 CAD 和螺钉工具空间验证）

- **A↔B：** 非贯穿内风道的止口定位，2×隐藏 M3 螺钉（优先从底面可拆）+ 2 个定位点，1–1.5mm 未压缩闭孔泡棉止口垫，转角处连续密封。需验证外框与内部通流截面不被螺丝座侵占。
- **B↔C：** 一体式双叶片可调芯，2 个共同侧转轴，角度目标 ±12°，两侧机械止挡；不得让指尖接触叶片尖锐边。推荐 M3 轴销/螺钉 + 低摩擦弹性垫圈，避免打印转轴直接在脆性树脂中长期摩擦。
- **A↔D：** 计划在 A 下部/侧壁设置 4 处局部加强承力座，孔距不从旧支架继承，先由真实安装干涉和受力分析确定；推荐金属支架避免薄树脂大悬臂。
- **D↔4040：** 2×M5 T 型螺母、沿槽分布，分开 D1 立柱版本与 D2 横梁版本；避开基座角马。需包含两种槽口方向装配检查。
- **A↔风扇：** 保留 124×124mm、105×105mm；支架完全避开接触面，1×密封垫（不包括用户自装的防护网）。

## 五、低成本风向调整的合理边界

- 第一版优先做**上下方向约 ±12°**，通过一件可动双叶片内芯实现，较为便宜、不会造成整机摇摆。
- 左右方向优先通过左右镜像模块固有内倾角与安装位置选择实现；如果确需**连续左右偏转**，第二步增加小范围偏航支架或独立可调立叶，不直接引入球头关节。
- 叶片调节有可能增加风阻/噪声；验收需要在三种叶片角度下比对同一风扇的实际风速和噪声，不应把几何面积比例当作风量保留比例。

## 六、严格的打样前放行门槛

1. 用 CAD 制作 A/B/C/D1/D2 及左右镜像参考装配；孔距、螺丝工具路径、转角机械限位无干涉。
2. 封堵风扇入口与出口，检查 A/B 分件接缝无额外空气通路；做小样接缝气密测试。
3. **先打单独的 A/B 止口试片和 C 转轴试片**，复核真实材料公差，不直接打印整件。
4. 4040 立柱内侧与横梁都要模拟角马/基座占用、风扇进气净空和装拆操作。
5. 对 120×25/38/50/55mm 风扇做装配包络，确保 38mm 厚风扇作为默认设计基准。
6. 金属支架校核 1kg 假设载荷与振动工况（质量、悬臂以装配重量实测修正），检查紧固件及塑料嵌件拉脱力。
7. 切片报告分别记录风道、固定前罩、可动内芯和两款支架的制造工艺、支撑、单件成本，比较**每套总价**而非只比较主壳体积。
8. 对比 R4.12 的同型号风扇、相同 PWM 条件下的出口风速、漏气、噪声；不得宣称已验证性能。

## 七、优先开发顺序

(1) 固定 A 外部受力接口和风扇密封面 → (2) B 与 A 的止口/密封 → (3) D1/D2 立柱横梁安装 → (4) C 可调风向内芯 → (5) 模型与切片成本比较 → (6) 小样测试 → (7) 正式打样。

**成本判断：** 分件设计不一定让完整单套的打印费立刻下降——接口、螺丝座也会增加材料——但能降低外观迭代、双色、升级及报废重印的成本，也能让前罩选择适合低成本批量生产的工艺。
