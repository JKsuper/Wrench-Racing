# LC8 工程打样候选

- 主风道A保持一体；LC7百叶正面装入干涉已修：固定中脊由A移到可拆前盖D，装B后再装D。不得恢复A固定中脊或端桥。
- 型材接口Ø7mm通孔，兼容M4/M5/M6螺栓与对应T螺母，不是让六角螺母穿孔。安装板6×68×44，三孔[(0,-29),(0,-9),(20,-29)]，每次选两孔。筋移到Y±32，已检查外径18/厚1.6垫圈示例。
- M4/M5/M6均需大平垫，M4不能裸头压Ø7孔。先把C装到型材，再装A，保证螺钉头工具空间；长度依实际T槽T螺母选，不统一承诺16mm。
- 百叶、底盖和前盖仍按非沉头M4×16、0.5mm薄平垫、3.5mm螺母包络核对。普通M4平垫厚度不一定0.5，必须实测。
- 保留LC6四角宽承压/耳根筋，38–40风扇，18×14/R2四针孔，STRIKE，M4百叶±12及四向换边。D左右同件，品牌不镜像。
- 后向安装须实物核对出线口、螺钉头和线束弯曲；四向测试仅外形占位，前侧立柱顶面Z=0条件保留。
- 当前4主STL，30项几何回归＋独立导出核验，不代表实际切片、载荷、蠕变、气密或100元已确认。
- 可交店做首轮工程验证样，但A内部支撑需先回传切片确认。12_Prototype_Review/PRINT_SHOP_RIGHT_LC8是单侧交店包；OPTIONAL试片非产品件。
