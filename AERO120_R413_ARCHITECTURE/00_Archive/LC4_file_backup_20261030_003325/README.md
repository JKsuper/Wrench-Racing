# AERO120 R4.13-LC4｜三件打印结构

本轮按用户要求取消金属结构件：底盖与安装支架改成一体打印件，取消抱箍、金属支架及隔柱。保留普通螺钉、螺母、垫圈及4040型材T螺母。

## 每侧打印三件

| STL | 功能 |
|---|---|
| 01_A_integrated_shell.stl | 风道、STRIKE前脸及风扇外壳，带4个外围固定耳 |
| 02_B_twin_louver.stl | 共轴活动双百叶 |
| 03_C_printed_base_mount.stl | 底盖、封口法兰、加筋安装支架一体件 |

默认右侧，各打印1件。左侧运行build.py --hand L覆盖同名三文件，同时更新PRINT_SELECTION.json。当前06_STL仅三份文件。五金和泡棉需按BOM另备。

## 风扇如何固定

先穿KF2510四针插头，再从底部放入38–40mm风扇。顶部贴连续密封泡棉，底部用一整圈泡棉调整夹持余量。将打印底盖从下方向上对齐，4颗外围M4螺栓穿过底盖与外壳固定耳，顶部用普通螺母及平垫圈锁紧。无需热熔嵌件或打印螺纹。

Ø4.8通孔配M4，名义径向余量0.4mm；M4x20为候选长度，需结合垫圈、实际耳厚及螺母啮合实装核对。四个固定点位于风扇侧壁外，不将孔打入空气通道。不能依靠过度拧紧压紧泡棉，应检验预压与塑料变形。

底盖有Ø110进气开口，仍需用户自备防护网。顶部风扇密封圈、底盖外圈密封和底部缓冲圈用途不同，不互相替代。

## 打印支架

底板厚4mm，侧安装壁厚6mm，两道三角筋厚3mm；普通M5螺栓直接将侧壁固定到4040槽内T螺母。三孔中竖向两孔用于立柱、横向两孔用于横梁，不再使用6mm金属隔柱。具体槽型、螺栓头工具空间和角码避让需实物核对。

保留121.6mm方腔、43mm轴向空间、四针14×10mm/R1穿线孔、割缝软密封片、战斗式STRIKE和百叶±12°目标。打印构件体积约209.34cm³，含新增打印底盖支架；此前LC3的150.41cm³不含金属支架体积。该变化不等于报价涨幅，整套100元目标仍未报价确认。

17项自动检查通过：三STL网格、单实体、装配与四螺栓对孔、底盖竖向装配路径、风扇厚度、公差余量、插头通道、两侧枢轴、百叶限位、压力侧封堵闭合及双安装包络等。未进行实际切片、材料强度、层间拉脱、蠕变、振动、检漏或气动测试，当前仅供工程打样评审。

## 目录与运行

源码沿用03_Codex/simple_lc2路径，版本为LC4；build.py生成STEP/STL与装配，views.py生成CAD预览，test_engineering执行检查。05_STEP为左右物理件，06_STL为当前三件打印文件，07_Assembly为装配，08_BOM为采购与预算，09_Test_Reports为实测范围报告，10_Previews为图，11_Manufacturing为打印要求。旧金属方案归档，不再作为当前制造文件。
