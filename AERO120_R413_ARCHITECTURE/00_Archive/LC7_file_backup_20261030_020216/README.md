## 前饰盖

前框名义134×76mm，厚3mm，角部斜切；上方品牌台和下方固定耳使总外形更高。Wrench Racing浮雕位于正面上方，名义字号6mm，凸字与前盖一体。前盖不包裹风道顶部，不改变主体的空气密封功能。

前下方用两套M4×16、普通M4螺母、四片0.5mm平垫独立固定。螺钉从后侧装入，螺母在正面下方锁紧；真实工具与用户螺钉头型需实装核对。名义夹持至螺母末端14mm、16mm头下长度余2mm，不得直接套用沉头螺钉长度。换色从前方取下，不需拆风扇、底盖或百叶转轴，不改变原百叶阻尼设定。

饰盖不是密封风道的延长段，其外围留空是设计间隙。检查中将原出口的空气截面延伸到饰盖位置，与D无实体重叠；并验证百叶±12°离散行程和向前拆卸路径。几何无阻挡不证明实际流量/噪声不变。

## 打印与成本

前盖可按背面朝平台、凸字朝上作为切片候选；如需双色，可按实际文字起始层暂停换丝或后期涂字。图片橙框白字为配色示例，STL没有颜色信息。未实际切片，不宣称无支撑或单价下降。

按PETG密度1.27，D理论净重约11g，含前盖整套约286g；支撑、裙边、填充差异和失败损耗未计。小前盖减少换色时的重打量，首套是否便宜仍需包含工时、支撑与五金的报价。单侧100元目标未确认。

## 保留的设计与验证

四角28×28局部宽承压、14mm耳根筋、孔外侧名义余肉6.6mm；主固定M4×16、底盖四向旋转；38–40风扇；18×14/R2四针出线孔；STRIKE中脊及M4百叶保留。前侧高立柱仍可能挡风，本轮占位顶面Z=0。
