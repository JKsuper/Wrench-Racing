# LC7制造说明

前饰盖D仅为出风口外圈，不是整条风道外壳或密封延长。厚3mm，正面上方Wrench Racing字体已实体化，查看STEP/STL不依赖字体。重建使用Arial Bold。前盖左右通用，不镜像。

背面平面朝下、文字朝上为切片候选，文字层可做暂停换丝/多色或后期涂字；实际层号与支撑须由切片确认。不同颜色PETG批次的收缩、孔径和表面配合应试片验证。

两个前下方M4螺钉轴向沿Y，头部在后、普通六角螺母在前，平垫0.5mm/面。名义夹持14mm与16mm头下长度核对，给螺母余2mm；未验证任何特定螺钉头或扳手外形。需先试装后侧操作空间，允许在装前饰盖前预装螺钉，不依靠过拧压紧塑料。

前框与百叶转轴独立，不需为换色松开轴螺母。前盖前向拆卸的离散路径、原出口延伸截面及百叶半度采样无实体碰撞，不代表真实风量、噪声或手感已验证。

A/C保留LC6加宽四角和耳根筋，需验证PETG层间、拉脱、蠕变和振动。主风道一体，未增加空气通路分件接缝。原顶部罩的固定耳已移除，不能把旧A/D混装。
