# LC6制造说明（优先于旧版）

装饰壳：1.2mm薄壁，0.6mm名义配合，不使用脆弱卡扣。先做壳体侧壁/安装耳配合试片确认收缩、手感和0.5mm平垫尺寸。两颗独立M4螺钉只需夹紧到不晃，不可高扭矩压裂装饰耳。外罩上提路径已做离散几何检查，真实工具和机架顶部空间仍需试装。

PETG和不同颜色批次的收缩/表面差异需实测，不保证换料后直接互换。若需缓冲，可试配少量压缩后不超过0.6mm的薄泡棉贴；这不是空气密封件。外罩不参与主风道气密和承载。

品牌为顶部0.8mm浮雕，名义字号9mm，Arial Bold；查看导出模型不需字体，重建需可用字体。白字配色是涂色/双色示意，不代表单一STL自动生成双色。D为左右同一件，不镜像。

四角：A、C均加宽承压，孔外侧名义余肉6.6mm；A局部耳根筋高14mm并连接两面壳壁。平垫圈需落在平整支承面，螺母上方需留半径7mm工具通道。孔周厚度A5mm/C4mm不增加，沿用非沉头M4×16及普通螺母。旧版窄圆耳方案停止作为当前制造来源。

先验证打印方向和支撑清理，再用实际风扇质量及重心做耳根拉脱、支架弯曲、温升蠕变、振动和拆装试验。几何加宽与加筋不证明承载已经合格；未运行有限元分析或任何实物强度试验。
