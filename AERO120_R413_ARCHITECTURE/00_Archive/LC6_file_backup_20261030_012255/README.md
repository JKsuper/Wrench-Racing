# AERO120 R4.13-LC6｜Wrench Racing换色罩与四角加强

本轮完成三项：独立换色装饰壳、四角螺孔连接区加强、顶部Wrench Racing品牌浮雕。原风道空气通路保留；仍为未切片、未报价和未进行承载实测的工程候选。

## 打印清单

| STL | 用途 |
|---|---|
| 01_A_integrated_shell.stl | 密封风道与风扇壳；四角宽承压区、耳根筋及外罩独立安装耳 |
| 02_B_twin_louver.stl | 活动双百叶 |
| 03_C_printed_base_mount.stl | 加宽四角的底盖与四向安装支架 |
| 04_D_Wrench_Racing_colour_shell.stl | 可选的独立换色罩，左右通用 |

功能主体仍三件；想换颜色只需重打D。D包住风道上部的顶部、左右两侧和后背，前部与底部开放，前脸和风扇室保留主体底色。默认A/B/C为右侧；左侧用build.py --hand L覆盖同名文件。D总是同一通用件，不镜像，所以品牌不会反写。

## 装饰壳和品牌

D名义壁厚1.2mm，与主体0.6mm间隙。松开两颗独立M4×16后向上提起，无需拆风扇、底盖或百叶。两个普通螺母、四片0.5mm平垫单列在BOM；不增加薄小卡扣。薄壳仅装饰，不用于手提整机。

Wrench Racing位于顶部，Arial Bold名义字号9mm、浮雕高0.8mm，朝出风口/驾驶者方向阅读。字体已经转成真实CAD实体，STEP/STL查看不需安装字体；从源码重建仍需对应字体。品牌凸字与外罩为一个零件。

10_Previews/Wrench_Racing_colour_shell.png为真实CAD配色示例：橙色壳与白字可通过不同颜色材料、涂字或合适的双色工艺实现，STL本身不含颜色。单色打印也保留凸字。外罩可单独换成黑、灰、红等颜色，不必重印风道。

## 四角螺孔修订

原窄圆耳改成约28×28mm局部承压区，同时连接相邻两面壳壁；外壳耳根再向上加14mm高局部筋。底盖对应位置也加宽。孔外侧名义余肉由原约3.6增至约6.6mm，孔仍Ø4.8。普通M4螺母位置留出半径7mm操作空间，没有打印螺母陷槽。

为兼容现有M4×16，孔位夹持厚度不增加：底盖4＋密封1＋外壳耳5＋平垫共1＋螺母包络3.5＝14.5mm。加强放在周边和耳根，不靠增加螺栓夹持厚度解决。此为几何修订，没有承载倍数或强度合格结论；必须验证PETG层间、耳根拉脱和长期蠕变。

## 材料预算

按PETG密度1.27g/cm³，A/B/C强化主体约274g净重；D约56g；含罩约331g。以上是CAD实体满填体积换算，未计支撑、裙边、填充差异和损耗，不是切片结果。新增外观件应单独报价，单侧100元目标仍未确认。

## 兼容与验证

38–40mm风扇、121.6mm方腔/43mm轴向、M4×16转轴、18×14/R2四针穿线口、STRIKE前脸、±12°和底盖四向旋转保留。前侧型材仍应终止于风口下方；本轮占位顶面Z=0，不代表任意高立柱均适用。

27项几何检查通过，包括外罩静态与上提路径、外罩螺栓通道、品牌实体、镜像主体与通用外罩、四角承压材料和原有装配/百叶/风扇/插头/压力侧闭合检查。没有承载、疲劳、蠕变、摩擦保持、气密、气动及打印公差实测。
