# AERO120 R4.13-LC1｜100元目标成本重构

用户要求：单侧整套（不含风扇）目标≤100元。本轮以此重新设计，旧项目镜像中的方盒重建版作废，不作为制造来源。**目前为几何评审候选；没有供应商报价，不能声称已达到100元。**

## 本轮结构

- A：贴合转弯包络的折面短风道，1.8mm名义薄壁，局部承力环筋和四个盲孔加强点，去除大块实心侧座。
- B：1.8mm薄壳STRIKE前罩，中脊突出、上下凹槽；后端6mm搭接，斜角连续密封圈，两颗前下方M3沿轴向拉紧。外观按架构重建，不宣称恢复R4.12原曲面。
- C：上下叶片及两端侧颊一体成形，共同俯仰轴，不用两组独立轴和连杆。目标±12°，外侧小圆销与固定止挡限制超程。
- D：一款2mm薄板、两道R2折弯的通用支架，四个共用风道固定点；外端竖排孔用于立柱，横排孔用于横梁。一侧只需一件支架。
- 风扇：120mm外置，默认38mm、检查25/38/50/55mm厚度。124×124×5mm法兰、105mm孔距、Ø110入口。支架不进入风扇单片垫片的密封层。

## 重建与检查

Python 3.12，安装 `03_Codex/low_cost/requirements.txt`。在该源码目录运行 `python build.py`，再运行 `python -m unittest -v test_engineering`。构建报告记录源码SHA256；源码修改后必须重新构建再测试。

本机CAD依赖位于项目镜像的`.runtime`，不重复安装到Downloads。可设置环境变量`AERO120_RUNTIME`为该依赖目录。未配置时使用正常Python环境中的包。工程文件不依赖zip分发。

坐标mm，X横向、+Y出风、+Z进风；左右以YZ面镜像。参数中前段局部枢轴Y=94，整体前移11后实际Y=83、Z=67。实际风道前端Y=73，前罩尖脊Y=93；外部止挡最前至Y=102。整个塑料件包络约164mm前后长。

## 成本与放行

体积仅用于材料比较，不等于打印重量、支撑量、加工时间或报价。整套目标拆为打印60、金属15、紧固件12、密封3、起步/运费分摊10元。以上是预算上限，不是市场价格。数量尚未确定，暂按小批量打样询价；首套可能超预算。

风道与前罩/转轴的密封、薄壁打印、嵌件拉脱、支架承载振动、实际4040槽型与角码避让、流量噪声均未实测。需要先做接口试片、实际切片与报价，再决定完整打样。详见04_QA/LC1_打样门槛.csv及11_Manufacturing/制造与风险.md。
