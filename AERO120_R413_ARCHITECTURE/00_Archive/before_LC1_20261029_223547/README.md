# AERO120 R4.13 — 模块化短风道设计基线

该更新包用于减少后续返工，明确三项设计：可拆卸造型前罩、低成本导风角度调节、4040 立柱及横梁兼容。**不是已经完成的 CAD。**

文件夹：
- `01_Schematics/`：装配架构/气流/支架结构示意（**非正式工程尺寸图**）
- `02_Design_Brief/`：基于 R4.12 现有源码核对的完整设计基线
- `03_Codex/`：下一轮建模任务 AGENTS.md
- `04_QA/`：制造与测试验收清单

主版本仍是 **R4.12 的真实 CAD**；R4.13 尚需参数化建模、支架承载验证、实际切片和风量实验。
