# AERO120 R4.13-LC2｜内置风扇与两件打印结构

本轮按用户审阅意见重构：38–40mm厚风扇嵌入底部，金属封口法兰同时作为外围安装支架；前罩与风道合并，取消大部分细碎紧固结构。**仍为未报价、未实测的工程候选。**

## 只打印两件

`06_STL/01_A_integrated_shell.stl` 是外壳、风道、STRIKE前脸的一体件；`02_B_twin_louver.stl` 是共轴双百叶。默认右侧，每侧各打一件。金属封口安装件C、抱箍、垫圈、泡棉、风扇和4040均不在打印STL目录。原20个STL及旧工程归档到00_Archive，不与当前交付混放。

左侧模型已提供STEP；需要左侧STL时在源码目录运行 `python build.py --hand L`，覆盖同名两STL，同时更新PRINT_SELECTION.json。不要把左右两套都当作单侧所需零件。

## 38–40mm与公差

- 方形内腔121.6×121.6mm，120mm风扇每侧名义余量0.8mm。
- 内部轴向总空间43mm；顶部风扇密封泡棉按装配1mm建模。
- 40mm风扇底部整圈缓冲泡棉按装配2mm，38mm按4mm；选合适泡棉厚度提供预压，不使用多块打印垫片。
- 测试包含120.4×120.4×40.5mm尺寸压力样本；不代表已覆盖实际打印收缩与具体风扇的所有公差。
- 百叶轴孔Ø3.8配M3螺钉，靠弹性垫圈与螺母定位，不要求打印轴孔过盈。所有小螺母槽、塑料螺纹及侧面嵌件已取消。
- 后侧Ø7走线孔是候选位置，需按实际线束和护线套图纸复核。外翻边应避开上方抱箍，不能省略护线和止拉。

## 安装结构

C为1.5mm金属平板，两边折弯形成托架；底面有Ø110开口用于进气，兼作风扇封口法兰。风道外侧两处宽托边承担定位/支承，外圈用一只成品抱箍夹紧，无塑料安装孔。右侧开口槽允许外壳从前方向后滑入；离散路径已检查，实际泡棉摩擦/线束和操作空间待实装。

C外侧有三处Ø6.5安装孔：立柱选竖向两孔，横梁选横向两孔，每次只用两颗M5。两只6mm金属隔柱留出空间。实际4040槽型、T螺母、螺栓长度和角码避让尚未冻结。

风扇—风道只有顶部一道受压密封；底盖另有壳体周圈密封，底部缓冲圈负责夹持，不能把这些不同用途的泡棉当作同一个界面。支架不夹在风扇出风面与上部风道之间。底部仍需用户防护网，不能用封口法兰的Ø110孔代替护网。

## 取舍与成本

可拆前罩功能本轮合并；更换外观要重打外壳。打印主件3→2，默认STL20→2。内置围壁使塑料总体积从LC1的142.91升至约148.62cm³（约+4%），金属封口件也有材料增量。因此本轮优点是减少零件、孔位、装配和对打印小特征的依赖，**不宣称材料更省或单价更低**。

整套目标仍≤100元、不含风扇。分项预算在08_BOM，全部未报价；请先用实际工艺切片并询价。1.8mm薄壁、塑料托边、金属托架、抱箍保持、泡棉预压、轴孔泄漏和风量噪声均需实物验证。

## 文件及运行

03_Codex/simple_lc2：参数源码与测试；05_STEP：左右独立物理件；06_STL：当前选择的两打印件；07_Assembly：立柱/横梁和爆炸STEP；08_BOM：采购与预算；09_Test_Reports：实际检查；10_Previews：CAD装配/剖面；11_Manufacturing：金属展开候选及打样要求。

源码目录安装requirements后，运行 `python build.py --hand R`、`python views.py`、`python -m unittest -v test_engineering`。本机可以直接运行run_local.ps1，复用已有CAD依赖，不必重新下载。14项检查通过仅表示当前标注范围的几何候选通过。
