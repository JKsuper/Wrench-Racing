# LC2 实际检查结论

用户确认38–40mm风扇并要求留公差。两件打印件合计148.62cm³，较LC1的142.91cm³增加约4.0%；单侧打印构件3→2，默认STL20→2。金属件、泡棉和左右重复STL不再混入当前打印目录。

取消前罩固定螺钉、风扇四角固定孔、侧面四点嵌件、打印螺母陷槽。打印件仅有4个必要的百叶轴孔（壳体2、芯2）和1个后侧走线孔。金属安装翼三孔选二；成品抱箍用自身螺丝夹紧。

14项自动测试通过：源码/报告一致、有效单实体、仅两STL、网格拓扑、装配名义碰撞、±12度49处半度采样、±12.1/13超程止挡、38/39/40及40.5mm压力包络、压力侧封堵闭合、两安装包络及参考件、名义公差余量、走线孔、金属单件两折弯、15个前向滑入位置。

实际建模的公差余量是名义值，未签核具体打印工艺。105孔矩作为风扇标准参考保留，夹持式安装不再开四个无用孔；38–40mm内置版本也不宣称当前壳可装50/55mm。

压力侧闭合测试临时封堵风扇座入口、出口和枢轴孔；不认证实际轴孔动密封与风扇泡棉气密。风扇室走线孔位于压力侧密封之外的风扇进气侧，需要护线与止拉。五金螺纹、抱箍夹紧力、真实T槽与角码以及护网均未完成采购型号签核。
