# AERO120 R4.13-LC3｜四针出线与STRIKE外观

本轮在LC2基础上修改KF2510四针穿线口和出风口造型。38–40mm风扇、121.6mm方腔、43mm轴向空间、两件打印结构、4040双安装及100元目标保持。工程仍未报价和实测，不能直接量产放行。

## 四针插头穿线

后侧开口由Ø7改为14×10mm圆角长孔（R1），中心Z=-24，避开外圈抱箍。参考2510四针壳宽10.76±0.3mm；厂商外形有差异，本轮按12×8mm横截面、16mm轴向包络做直线穿孔检查。原始图纸：https://everconn.com/Uploads/2022-03-16/6231af3b8f931.pdf 。这不是对所有KF2510供应商外形的通用保证。

装配必须先穿插头，再放入风扇；风扇已占满内腔后，不能让插头穿过约0.8mm侧隙。穿完后贴22×18mm带割缝软密封片收口，中心线孔按实际线径裁切并做外侧止拉；该软片不打印，不增加壳体小螺孔。模型4mm中孔仅作参考。

## STRIKE外观

出口肩角增至明显斜切，前框约122×64mm；前伸箭形中脊、上下薄眉刃及深凹双槽强化战斗造型。装饰延伸只加薄片，没有额外侧壁通风孔。前伸中脊前缘已留小平头，仍需实物确认触碰安全和打印强度。

外壳与活动百叶仍为两个打印件。塑料合计约150.41cm³，比LC2的148.62cm³增加约1.2%；不承诺报价同比变化。百叶±12°采样无碰撞，止挡仍保留；修正并新增检查两侧枢轴孔贯通。
