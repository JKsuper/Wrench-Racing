# AERO120 LC3 当前工程约束

用户本轮指令优先于原03_Codex/AGENTS.md和LC1架构：风扇嵌入底部，底部法兰封住、外壳小孔走线、减少打印构件与小孔，外围螺丝支架安装。用户确认风扇38–40mm，留公差余量。允许合并原前罩功能，以减少零件；不再冻结可拆前罩。

- 单侧整套不含风扇目标≤100元；未报价不宣称达标。
- 仅两个主打印STL，外壳A、活动百叶B；金属封口安装件C、抱箍、泡棉和五金不输出打印STL。
- 默认38–40mm共用壳：内腔121.6mm，轴向43mm。不能声称当前壳兼容50/55mm，需变更参数和复测。
- 保留120mm风扇、Ø110空气入口、105mm孔距参考、左右镜像、4040立柱/横梁和±12°目标。因夹持不再使用风扇四角螺栓，105孔距只做参考，不钻无用孔。
- 新嵌入壳体外宽125.2mm，替代原124mm外置法兰尺寸；不要为了维持旧外径压缩公差。
- 无打印螺纹、螺母槽或热熔嵌件；打印孔只保留2+2百叶轴孔及1走线孔。金属支架三孔中选两孔安装。
- 源码03_Codex/simple_lc2。build.py后运行views.py及test_engineering。默认仅R侧两STL，--hand L覆盖同名为左侧；不要堆积左右与厚度重复文件。
- 旧版本移入00_Archive，原01/02/03架构基线只作追溯。几何测试不等同承载、气密、气动或实际制造公差验证。
