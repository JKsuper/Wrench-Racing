# LC3 制造与装配

## 本轮公差策略

普通通孔、宽托边、成品螺母/抱箍和整圈泡棉，取代打印螺母槽、热熔嵌件、小定位键和四点侧座。风扇内腔121.6方，名义120mm外框每侧0.8mm余量；即便用120.4mm外框，名义仍每侧0.6mm。若打印后内腔总尺寸缩小0.4mm，则该压力样本仍仅余每侧0.4mm；这只是尺寸算例，不能作为已知工艺能力。

43mm总轴向空间用顶部1mm压缩密封圈、38–40mm风扇以及底部4–2mm整圈缓冲泡棉构成。泡棉未压缩厚度和压缩力需实测选型，不应把硬胶条厚度当作弹性余量。若实际框架有凸筋或出线凸台，需修改包络复测。

## 装配顺序

1. 清理外壳，检查轴孔/走线孔，安装护线套；在顶部风扇座上贴连续密封圈。
2. 从底部放入风扇，线束穿后侧小孔，完成外侧止拉。配选对应厚度的一整圈底部泡棉。护网另装。
3. 将外壳两宽托边对准金属托架：右侧槽从前缘开口，沿-Y从前方滑入；左托边放在另一金属上缘。为全行程拆出预留约140mm前向空间；拥挤座舱可先卸下整套托架后维护。离散路径不代表泡棉摩擦和真实线束不会阻碍操作。
4. 外围装成品抱箍，夹持高度在走线孔上方，确认不夹线。宽托边承担支承，抱箍防分离与滑动。不得通过过度拧紧把薄壁夹裂；夹持力和防脱需试验。
5. 装百叶两侧M3轴向螺钉、弹性垫圈和防松螺母；调到不会自行漂移且能手动转动。轴孔留间隙，不用过盈插销。
6. 立柱用金属外翼的竖向两孔；横梁用横向两孔。装6mm金属隔柱及对应T螺母。需要按实物型材复核螺钉长度和抗转能力。

## 金属件C

1.5mm薄板，底面Ø110进气孔，左右两个90度折弯，内R1.5候选。右侧上延作为型材连接翼；开口槽容纳塑料宽托边。只有三处Ø6.5型材安装孔，单次选两处。材料牌号、防锈、去毛刺、折弯顺序及应力集中需厂家复核。

展开DXF使用K=0.4，未做折弯扣除校准、装夹避让或结构合格验证，只能用于询价和工艺讨论，不能直接投料。抱箍是采购件，参考包络没有模拟蜗杆、带齿或真实弯曲夹紧行为；必须按壳体周长、支承翼和护线套位置选择合适实物后复测。

## 打印与风险

一体壳取消前罩接缝，但增加整体打印方向和内部支撑处理难度。当前未运行切片，不承诺支撑更少或报价下降。先比较出口朝下、入口朝下两种切片方向的支撑可取出性、尺寸收缩、托边层向和表面质量。百叶独立打印以保留活动功能。

先打风扇框角/轴孔公差试片，或让供应商测量与补偿内腔；不直接凭STL名义余量下整单。四针插头先从14×10mm/R1开口穿过，再装风扇；以22×18×1mm带割缝软密封片收口，按实际线径裁切中孔并做外侧止拉。线孔中心Z=-24，软片上缘低于抱箍，不增加打印件或小螺钉。不同厂商锁扣外形需实物试穿。

LC3塑料总体积150.41cm³，较LC2增加约1.2%；主体仍只有两件打印件。底部金属法兰托架约19.5cm³，不能忽略其材料与加工费用。100元为预算，没有任何供应商成交报价。

承载、托边蠕变、抱箍防脱、转轴磨损、风扇温升、漏风和气动噪声均未实测。薄壁、少孔和名义无碰撞都不能替代这些验证。
