# LC5打印结构要求

取消钣金、金属抱箍及隔柱，不直接把薄钣金模型改材料。底盖4mm、侧壁6mm、筋3mm；四个M4闭合点采用Ø4.8普通通孔，配普通螺母和两面平垫圈。型材安装侧用M5和T螺母。

先穿四针插头，再装风扇。底盖从下方靠合外壳，四组外围螺栓夹紧；泡棉负责预压和密封，外壳侧壁限制风扇横向移动。需检查泡棉压缩后风扇是否仍有轴向松动，以及螺母啮合、头部承压面和四耳平整度。普通M4x16/M4x16均为候选长度。

C以底板朝下为候选打印方向，优先保持两道三角筋连续成形。侧壁层间弯曲、螺母承压导致的裂纹、塑料长期蠕变以及层向均需打样验证；当前未切片，未确认材料牌号、层高、填充或壁线数，不可按实体有效直接生产承力件。普通脆性材料同样没有承载合格结论。

A外壳新增四个5mm厚外围耳，根部连接需检查支撑和层向；不能因通孔容易打印而忽略耳根拉脱。使用较大平垫圈并逐步对角压紧，不以高扭矩掩盖翘曲。实际允许扭矩需通过所选材料试片确定。

先做孔径/风扇角部/耳根试片，确认120mm外框和38–40mm厚度可装入。KF2510四针包络16×12×18mm只用于几何检查，具体锁扣外形仍需核实。软密封片保持可拆，避免增加打印小卡扣。

打样前必须验证：四耳与底盖的拉脱及弯曲、侧支架静载和振动、风扇运行温升下的蠕变、百叶保持与磨损、密封泄漏、进气净空及噪声。当前没有FEM或实物承载结果。整套100元是预算目标，新增打印底盖后必须重新切片询价。


## LC5优先变更

本节优先于旧版细节：轴孔Ø4.8，普通M4螺母，不用M3；非沉头M4×16按头下长度。百叶夹持总厚14mm，底盖总厚14.5mm，均按0.5mm平垫与3.5mm螺母包络。底盖外壳耳现5mm，四点坐标±68，需重新检验耳根强度和蠕变。摩擦片装配厚1.5mm，普通螺母需防松与保持测试。

孔18×14/R2，软片28×24，16×12×18插头压力包络仅作设计检查。底盖可按90度换边；前侧安装时型材需终止于风口下方，本次占位顶面Z=0。不得把占位检查视为任意座舱适配。
