# AERO120 R4.13-LC5｜现有M4五金与保守出线口

继续三件打印结构。此轮把百叶转轴改为用户现有的非沉头M4×16与普通M4六角螺母；不再要求M3螺母。出线孔由14×10扩大为18×14mm/R2。底盖四点对称，转90度可换前后左右安装边。

## 百叶五金，每侧风口

| 材料 | 数量 | 说明 |
|---|---:|---|
| M4×16非沉头螺钉 | 2 | 按头下16mm建模；沉头螺钉不能直接套用此长度核对 |
| 普通M4六角螺母 | 2 | 本轮包络厚3.5mm、对边7.2mm；实测你已有螺母 |
| M4平垫圈 | 4 | 建模厚0.5mm/片、外径9mm；厚垫圈需重新核对长度 |
| 摩擦软垫圈 | 2 | 候选内径4.4外径10mm，装配压缩厚1.5mm；按实物弹性选择未压缩厚度 |

外壳轴座与芯侧轴座重新排布，名义总夹持至螺母末端14mm，16mm螺钉约余2mm；不是直接将M3孔扩大。轴孔Ø4.8、轴座外径12mm。普通螺母可用于试装，防松、角度保持和反复调节磨损仍需测试，不能宣称已经可靠锁住角度。

底盖四组固定螺钉也统一为M4×16：底板4＋密封间隙1＋外壳耳5＋两面平垫共1＋螺母包络3.5＝14.5mm，名义余1.5mm。打印耳较上版减薄，必须做拉脱和振动验证。底盖另需4螺钉4螺母8平垫；M5型材固定仍按实际4040的T螺母选择。

## 保守穿线口

18×14mm/R2圆角孔，中心Z=-24。按16×12×18mm插头压力包络检查通过，不代表所有供应商KF2510的锁扣都相同。先穿插头，再装风扇；风扇入壳后的侧隙不是插头通道。

软密封片改28×24mm，孔四周覆盖5mm，中心线孔按线径裁切并做外侧止拉。走线孔上下保留外壳材料，后侧孔底距壳体下缘名义8mm；避开底盖和密封条。软片非打印件。

## 四向换边底盖

四固定点位于(±68,±68)，外壳朝向不变，底盖C旋转0/90/180/270度选安装边；仍只需同一个底盖STL。侧壁缩短并保留三角筋，避免前侧安装翼伸进出风口。四方向各有立柱/横梁占位装配，共8套右侧评审STEP。A与C的孔位已变更，必须使用本版成套文件，不能与LC4混装。

注意：四向检查使用顶端Z=0的立柱占位，型材位于风口下方；前侧若使用贯穿风口高度的立柱，仍可能遮风，需按实际座舱避让。这不等于任意高立柱在四向都适用。

## 交付与验证

06_STL仍为A外壳、B活动百叶、C底盖支架三件，默认右侧；左侧用build.py --hand L覆盖同名三件。源码沿用03_Codex/simple_lc2目录，参数/报告版本LC5，运行build.py、views.py及test_engineering。当前五金应使用本版BOM，旧M3清单已作废。

22项几何测试通过，包括M4五金参考包络、夹持长度、四向底盖/型材占位、出线孔剩余壁及扩大插头通道。承载、螺母防松、塑料蠕变、密封、气动及100元目标仍待实测/报价，未运行切片。
